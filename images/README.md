# Images Folder

## Required File

Add your profile photo here:
- **Filename:** `joe-finberg-profile.jpg` (or update reference in `index.html`)
- **Recommended specs:**
  - Format: JPG or PNG
  - Dimensions: At least 800x800px (square or portrait)
  - File size: Under 200KB (compress for web)
- **Used on:** Homepage (index.html)

## Image Optimization Tips

Before adding your photo:
1. Resize to appropriate dimensions (800-1200px wide)
2. Compress using tools like:
   - ImageOptim (Mac)
   - TinyPNG.com (web)
   - Squoosh.app (web)
3. Save as high-quality JPG (85-90% quality) or optimized PNG
