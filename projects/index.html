Laurelin agent harness

A laurelin terminal command that runs Laurelin's AI work. It is a fork of Prime Agent with about 10,000 lines of our own code, built in six days in September 2026. A coordinator model hands each task to workers such as Claude Code and Codex, with a router built on Jev, TypeSafe's judgment model.

Around that loop sit a ladder of checks, a deny-by-default approval gate, and a secret scrubber. More in An agent harness in six days. Link to the repo.

Captain's Deck

A read-only kanban plugin for Herdr, the terminal multiplexer I use to run coding agents side by side. It shows the flow of work across agents on one board. Link to the repo.
