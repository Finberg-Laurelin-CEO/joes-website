# Files Folder

## Required File

Add your CV/Resume here:
- **Filename:** `joe-finberg-cv.pdf` (or update reference in `index.html`)
- **Format:** PDF
- **Recommended size:** Under 2MB
- **Used on:** Homepage (index.html) - downloadable link

## PDF Optimization Tips

To keep file size manageable:
1. Export at medium-high quality (not maximum)
2. Embed only necessary fonts
3. Compress images within the PDF
4. Use tools like Adobe Acrobat or Preview (Mac) to reduce file size

## Additional Files

You can add other downloadable content here:

Make sure to link to them from your HTML pages and use descriptive filenames!

## File Naming Best Practices

- Use lowercase
- Use hyphens instead of spaces
- Be descriptive: `joe-finberg-cv-2025.pdf` instead of `resume.pdf`
- Include dates in filename if you update frequently
